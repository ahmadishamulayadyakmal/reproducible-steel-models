## What was actually completed

- Created `src/metalkit/` with `__init__.py` and `cli.py`; the CLI exposes
  `--version`, `--help`, and `info` and intentionally has no data commands yet.
- Added `tests/test_cli.py` covering the version string, help output, and the
  `info` subcommand.
- Declared runtime and development dependencies in `pyproject.toml` with
  `setuptools` as the build backend and `src/` as the package root.
- Added `.pre-commit-config.yaml` with formatting, linting, and YAML/TOML
  checks.
- Closed E01 with the four sprint notes and a v0.1.0 changelog entry.

## What failed / was not completed

- No pre-commit hooks were executed locally because `pre-commit` is not
  installed; the configuration is present but unvalidated.
- A GitHub remote is still absent, so no PR or CI result backs this sprint.
- Data ingestion commands (`ingest`, `validate`, `report`) are deliberately
  deferred to E02; `metalkit report` is not yet implemented.

## Technical decisions

- The CLI uses only the Python standard library so that `--help` works even
  before the scientific dependency stack is installed.
- Package version `0.1.0` is independent of the portfolio release `v1.0.0`,
  which is planned for W50.
